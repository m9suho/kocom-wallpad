# Release v2.0.13

## 버그 수정

### 🔧 일괄소등 "즉시 성공" 처리가 실제로는 동작하지 않던 문제 수정
- **문제**: v2.0.12에서 LIGHTCUTOFF의 confirmation timeout을 0.0초로 설정했지만, `asyncio.wait_for(..., timeout=0.0)`은 future가 미완료 상태면 즉시 `TimeoutError`를 발생시키므로 여전히 `No confirmation` 재시도 → `failed after 3 attempts` 오류 발생 (v2.0.10-beta.2.1의 원래 구현도 동일한 결함)
- **해결**: `gateway.py`의 `_sender_loop`에서 `timeout <= 0`이면 확인 대기 자체를 건너뛰고 전송 직후 성공 처리 (fire-and-forget)
- 확인응답이 없는 broadcast 명령(일괄소등)이 오류 없이 즉시 완료됨

## 테스트 항목
- ✅ 일괄소등 turn_on/turn_off 시 `No confirmation` 경고 및 실패 오류 없음
- ✅ 일괄소등 실행 시 조명이 실제로 꺼지고 개별 조명 엔티티 상태 반영
