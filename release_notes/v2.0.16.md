# Release v2.0.16

## Home Assistant 2026.11 호환성 수정

### 🔍 배경
- HA 2026.11.0에서 `RestoreStateData.last_states`가 제거되어 (`last_states_by_entity_id` / `last_states_by_entity_registry_id`로 분리), 통합구성요소 설정 시 아래 오류로 `setup_error`가 발생하고 모든 엔티티가 `unavailable`이 됨
  - `AttributeError: 'RestoreStateData' object has no attribute 'last_states'`

### ⭐ 변경 내용
- `gateway.py`: 상태 복원 시 `RestoreStateData.async_get_stored_state()`를 우선 사용하고, 없는 구버전 HA에서는 기존 `last_states`로 폴백

## 테스트 항목
- ✅ HA 2026.11.0에서 통합구성요소 정상 로드 (`loaded`), 조명/난방/환기/엘리베이터/가스밸브 등 엔티티 상태 복원 확인
- ✅ 이전 HA 버전 호환을 위한 폴백 경로 유지
