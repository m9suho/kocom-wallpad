# Release v2.0.15

## 일괄소등 구현 방식 변경 (개별 OFF 방식)

### 🔍 배경
- EW11 직결 테스트로 RS485 일괄소등 broadcast 패킷(dest 0x0E/0xFF, cmd 0x65)을 직접 전송해도 **월패드가 전혀 반응하지 않음**을 확인 (2026-08-30)
- 이 월패드 모델은 RS485로 일괄소등 명령을 수신하지 않는 것으로 판단 (물리 버튼 상태 broadcast만 송신)

### ⭐ 변경 내용
- `light.kocom_light_light_cut_off_0_0` turn_on 시:
  - broadcast 패킷 대신, **등록된 조명 중 켜져 있는 조명에 개별 OFF 명령을 순차 전송** (개별 명령은 확인응답으로 전달 보장)
  - 전송 완료 후 일괄소등 엔티티 상태를 on으로 갱신
- turn_off(해제) 시: 조명 복원 없이 엔티티 상태만 off로 갱신 (복원은 상위 자동화/씬에서 처리)
- 수신 처리(`_handle_cutoff_switch`)는 유지 — 월패드 물리 일괄소등 버튼 상태 반영

## 테스트 항목
- ✅ 조명이 켜진 상태에서 일괄소등 turn_on → 조명 모두 꺼짐, 오류 없음
- ✅ 일괄소등 엔티티 상태 on/off 반영
