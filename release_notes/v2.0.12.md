# Release v2.0.12

## 일괄소등(LIGHTCUTOFF) 기능 복원 및 수정

### 🔧 일괄소등 엔티티 복원
- **배경**: v2.0.11에서 일괄소등(LIGHTCUTOFF) 기능이 제거되었으나, 실사용에서 일괄소등 버튼이 필요하여 복원
- v2.0.10-beta.2.1에서 검증된 구현을 기반으로 복원:
  - `const.py`: `DeviceType.LIGHTCUTOFF` 재추가
  - `controller.py`: `_handle_cutoff_switch` (수신 패킷 처리), `generate_command`의 LIGHTCUTOFF 분기 (dest_dev=0x0E, dest_room=0xFF, ON=0x65/OFF=0x66) 복원
  - `entity_base.py`, `gateway.py`, translations: LIGHTCUTOFF 관련 처리 복원
- 에어컨(AIRCONDITIONER/CLIMATE) 제거는 v2.0.11 그대로 유지

### ⭐ 일괄소등 확인응답(confirmation) 대기 제거
- **문제**: 일괄소등 명령 전송 시 `No confirmation for 'turn_on' (attempt 1/3)` 경고 후 `Command 'turn_on' failed after 3 attempts` 오류 발생
  - 실제로는 월패드가 일괄소등을 정상 수행하지만 HA에서는 실패로 표시됨
- **원인**: 일괄소등은 broadcast 명령이라 월패드가 확인응답을 보내지 않음
- **해결**: `build_expectation`에서 LIGHTCUTOFF 타입은 확인응답을 기다리지 않고 즉시 성공 처리 (timeout=0.0초)
