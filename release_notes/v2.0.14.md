# Release v2.0.14

## 버그 수정

### 🔧 일괄소등 broadcast 명령 반복 전송
- **문제**: v2.0.13에서 일괄소등 명령이 오류 없이 완료되지만, 단발 전송이라 RS485 버스에서 유실되면 월패드가 명령을 수행하지 않음 (v2.0.10에서는 확인 대기 실패로 3회 재전송된 부수효과 덕에 동작했음)
- **해결**: 확인응답이 없는 명령(timeout<=0)은 같은 패킷을 3회 반복 전송(간격 0.3초) 후 성공 처리

### 🔧 난방(THERMOSTAT) climate 엔티티 복원 (v2.0.11 회귀)
- **문제**: v2.0.11에서 에어컨 제거 시 `Platform.CLIMATE`와 `climate.py` 전체가 삭제되어 난방 엔티티(`climate.kocom_thermostat_*`)까지 unavailable이 되는 회귀 발생
- **해결**: `climate.py` 복원(에어컨 제외, 난방 전용) 및 `PLATFORMS`에 `Platform.CLIMATE` 재추가

## 테스트 항목
- ✅ 일괄소등 실행 시 조명이 실제로 꺼짐 (반복 전송)
- ✅ climate.kocom_thermostat_* 엔티티 정상 등록
